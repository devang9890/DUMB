# AI Dumb ↔ Smart Translator

This is a full-stack web application that translates text between "dumb" (simple) and "smart" (sophisticated) language using the Google Gemini AI model. The application features a modern frontend built with React and a robust backend powered by Node.js and Express.

## Features

*   **Bidirectional Translation:** Translate text from simple to sophisticated language and vice-versa.
*   **Translation History:** The application saves and displays a history of past translations.
*   **Responsive UI:** A clean and modern user interface built with React and Tailwind CSS that works on all screen sizes.
*   **RESTful API:** A well-structured backend API to handle translation requests and data persistence.

## Getting Started

### Prerequisites

*   Node.js (v18.x or later)
*   npm
*   MongoDB (local or a cloud instance like MongoDB Atlas)
*   A Google Gemini API Key

### Setup

1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url>
    cd <your-repository-name>
    ```

2.  **Setup Backend:**
    ```bash
    cd server
    npm install
    ```
    Create a `.env` file in the `server` directory and add the following environment variables:
    ```
    PORT=5000
    MONGO_URI=<your_mongodb_connection_string>
    GEMINI_API_KEY=<your_google_gemini_api_key>
    ```

3.  **Setup Frontend:**
    ```bash
    cd ../client
    npm install
    ```

### Running the Application

1.  **Start the backend server:**
    ```bash
    cd server
    npm run dev
    ```
    The server will start on `http://localhost:5000`.

2.  **Start the frontend development server:**
    ```bash
    cd client
    npm run dev
    ```
    The application will be accessible at `http://localhost:5173` (or another port if 5173 is in use).

## API Endpoints

The backend exposes the following REST API endpoints:

*   `GET /api/translations`: Get all translation history.
*   `POST /api/translate`: Create a new translation. Expects a JSON body with a `text` property and a `mode` property ('dumb-to-smart' or 'smart-to-dumb').
